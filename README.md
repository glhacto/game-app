# One Tap One Life

**One Tap One Life** is a charity gaming platform built around a simple idea: turning a few minutes of gameplay into something meaningful.
Instead of asking users to donate money directly, the app generates charitable contributions through ad revenue while they enjoy fun mini-games.
This project has been designed to create an engaging experience while making it easy for anyone to support a good cause. Every 
feature has been built with the goal of keeping players entertained while encouraging them to come back every day.

### What We've Built

* 🎮 A collection of fun and interactive mini-games
* 👤 Secure user authentication and personal profiles
* 🔥 Daily streaks to reward consistent players
* 🪙 Points and rewards system
* 🏆 Global leaderboards and competitive tournaments
* 📈 Player progress tracking and game statistics
* ❤️ A charity donation system powered by ad revenue
* ☁️ A secure and scalable backend using Supabase
* 📱 Cross-platform development with React and React Native (Expo)

### Tech Stack

* React
* React Native (Expo)
* Supabase
* JavaScript
* HTML & CSS

This repository contains the complete development journey of **One Tap One Life**, from the frontend interface to the backend infrastructure. It showcases the design decisions, features, and technologies used to bring the project to life.
